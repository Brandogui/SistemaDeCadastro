# Sistema de Cadatro

[![NPM](https://img.shields.io/npm/l/react)](https://github.com/Brandogui/SistemaDeCadastro/blob/master/LICENSE)

# Sobre o projeto
A aplicação consiste em um sistema de cadastro de pessoas, com opção de login que irá salvar os dados do usuário no banco de dados e só permitirá o acesso à tela de opções caso o usuário tenha o usuário e senha digitado corretamente, além disso ele tem as funcionalidades de cadastrar novo usuário, pesquisar um usuário a partir do seu ID correspondente, atualizar um usuário modificando sua senha ou nome de usuário e listar todos os usuários do sistema, através do botão listar que irá exibir uma planilha com os dados.
